# Psychic Petals

Welcome to the **Psychic Petals** project! This repository is the home for both the open-source magical realism novel and the dedicated web platform built to read it.

## Overview

The project is divided into two main components:

### 1. [Psychic Petals Novel](./psychic-petals-novel/)
The core story repository. "Psychic Petals" is an open-source magical realism and slice-of-life novel. It focuses on the personal moments of characters in a world featuring a corporate-regulated hero ecosystem and psionic societies. Here you will find the finalized prose, outlines, and the story bible.
- [Read the Novel README](./psychic-petals-novel/README.md)

### 2. [Psychic Petals Platform](./psychic-petals-platform/)
The custom-built full-stack platform and web reading experience. It consists of a Next.js frontend tailored for an immersive reading experience, and a robust backend API to host, manage, and retrieve the novel's content.
- [Read the Platform README](./psychic-petals-platform/README.md)

## 🤝 Contributing

We welcome contributions to both the story and the platform! 

- If you are interested in writing, editing, or contributing to the lore, head over to the **[Novel Directory](./psychic-petals-novel/)** to see how you can help.
- If you want to help build the modern web platform (Frontend or Backend), check out the **[Platform Directory](./psychic-petals-platform/)** for setup and contribution instructions.
